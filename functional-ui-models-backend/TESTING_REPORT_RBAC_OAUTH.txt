1. EXECUTIVE SUMMARY & OBJECTIVES
--------------------------------------------------------------------------------

    The objective of this testing campaign was to rigorously verify the design,
    implementation, security boundaries, and user experience of the new
    Multi-Stakeholder Identity, Role-Based Access Control (RBAC), and Google
    Workspace OAuth 2.0 authentication architecture in Mad-Eye Moody Lens.

    Core Engineering Requirements Verified:
    1. Zero-Login Public Good: Unauthenticated visitors automatically land as
       "Guest" with full access to rapid fake/real image verdict triage (< 1s)
       and perceptual duplicate detection without any registration barrier.
    2. Explicit Authority Selection: Users wishing to sign in are presented with
       an institutional authority picker:
         - Government Official (Law Enforcement / CERT-In / Sovereign Cyber Cell)
         - Social Media Platform (Meta, Reddit, X Trust & Safety Moderation)
         - Investigative Journalist (Media Newsroom / Fact-Checker Desk)
         - Guest (General Public Citizen)
    3. Strict Sovereign Government Clearance: Government institution clearance
       is restricted EXCLUSIVELY to verified official sovereign government email
       domains (.gov.in, .nic.in for India; .gov, .mil, .gov.uk, etc. globally).
       Unauthorized personal accounts (e.g. @gmail.com) are strictly denied with
       HTTP 403 Forbidden.
    4. Two-Stage Google Workspace OAuth: Integrates standard Authorization Code
       grant flow with Google's live account chooser (prompt=select_account) and
       server-side cryptographic JWT token minting.
    5. Clean, Minimalist Top-Right Navigation: Removes all abrupt placeholder
       banners from the landing page. Replaces bulky persona buttons with a
       single, polished "SIGN IN" tab aligned with navigation typography.

    Testing Methodologies Employed:
    - Black-Box Testing (Functional API endpoints, HTTP status codes, payloads)
    - White-Box Testing (Branch logic, regex boundary checks, unit tests)
    - Integration Testing (Live Google OAuth handshake, SPA client routing)
    - Security / Penetration Testing (Subdomain spoofing, CSRF state, RBAC bypass)
    - User Interface & Usability Testing (Layout regression, typography alignment)
    - Static Analysis & Contract Parity (Ruff, TypeScript compiler, Parity checker)
